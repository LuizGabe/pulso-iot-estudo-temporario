Componentes independentes,
conectados por HTTP.

Simulador→API REST→Dashboard

Python · JSON · SQLite · HTML/CSS/JavaScript

O simulador envia. A API valida e armazena.
O dashboard consulta e apresenta.

  • VISUALIZAÇÃO Últimas leituras, gráficos e histórico
